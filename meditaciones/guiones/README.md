# Guiones · Colección de meditaciones guiadas

10 pistas preparadas para ElevenLabs. Cada archivo `NN-nombre.md` tiene los bloques listos para copiar.

**Cómo se han preparado**
- `[pausa breve]` → `<break time="2s" />` dentro del bloque.
- Frases largas (16 palabras o más) → `<break time="1s" />` en la coma central, para que la voz respire (máx. 3 por bloque).
- `[pausa larga]` → fin de bloque + **6 s** de silencio al montar.
- `[pausa muy larga]` → fin de bloque + **12 s** de silencio al montar.
- Las rayas (—) se han cambiado por comas y se han quitado las comillas «», para que la voz no haga pausas raras. No se ha cambiado ni una palabra, salvo en la Pista 1: "Bienvenida a este momento" pasa a "Bienvenida o bienvenido a este momento", como en las demás pistas.

`montaje.json` guarda bloques y silencios para hacer el montaje final.
`00-textos-originales.txt` es tu texto tal como lo escribiste.
